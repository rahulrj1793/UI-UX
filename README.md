# Text to URL Converter (Chrome Extension)

A lightweight Chrome extension popup that converts a title into a URL-friendly slug.

## What it does
- Converts text to lowercase
- Removes unsupported special characters
- Replaces spaces with `-`
- Collapses repeated hyphens
- Optionally combines the slug with a base URL

## Example
Input title:
`My First Blog Post`

Output slug:
`my-first-blog-post`

## Load in Chrome
1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this folder (`/workspace/UI-UX`)

Then click the extension icon and start typing.
